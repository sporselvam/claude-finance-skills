# Claude Finance Skills - Installation Guide

Thank you for downloading the **Claude Finance Skills** project.

This repository contains seven finance-focused Claude Skills designed to support financial analysis, forecasting, budgeting, cash flow analysis, cost-benefit analysis, and business data analysis.

## Written Installation Guide

### Step 1 – Open the Repository

Navigate to the **`skills`** folder in this GitHub repository.

Inside, you will find a list of all available Claude Skills.

---

### Step 2 – Choose a Skill

Open the folder for the skill you want to install.

Each folder contains a **`SKILL.md`** file.

---

### Step 3 – Download the Skill

Open the **`SKILL.md`** file and download it to your computer.

Repeat this process for any additional skills you wish to install.

---

### Step 4 – Open Claude

Sign in to your Claude account.

Navigate to:

**Settings → Skills**

Scroll down until you reach the **Skills** section.

---

### Step 5 – Upload the Skill

Click the **+** button to add a new skill.

Locate the downloaded **`SKILL.md`** file on your computer and upload it.

Claude will create the skill automatically.

Repeat these steps for any additional skills.

---

### Step 6 – Add Supporting Files (Optional)

Some skills may benefit from supporting documents, reference files, reports, spreadsheets, or templates.

If applicable, attach these files when configuring the skill to provide additional context and improve its performance.

---

### Step 7 – Use the Skill

Once installed, activate a skill in Claude by typing:

`/skillname`

Replace **skillname** with the name of the installed skill.

You can then provide your financial data, reports, spreadsheets, or business questions, and Claude will use the selected skill to perform the requested analysis.
